Privacidade e uso responsavel

Este aplicativo foi desenhado para respeitar a Lei Geral de Protecao de Dados (LGPD, Lei 13.709/2018).

1. Dados que consultamos

Apenas dados publicos disponibilizados pela Receita Federal do Brasil e por servicos que os republicam (Minha Receita, BrasilAPI, ReceitaWS e CNPJ.ws). O CNPJ consultado e enviado a essas fontes; nenhum outro dado seu e enviado.

2. Dados pessoais

  • CPF de socios: as fontes publicas disponibilizam o CPF mascarado (ex.: ***123456**). Este aplicativo nunca tenta descobrir, inferir ou desmascarar CPFs.
  • Telefones e e-mails: exibidos apenas quando informados no cadastro do CNPJ.
  • Enderecos: apenas o endereco do estabelecimento registrado no CNPJ.

3. Dados armazenados localmente

Somente neste computador, no arquivo configurado em DATABASE_URL:

  • Historico das consultas (CNPJ, razao social, situacao, data/hora).
  • Cache das respostas por {{ "%g" | format(cache_hours) }} hora(s) (CACHE_TTL_SECONDS).
  • Favoritos adicionados manualmente.

Voce pode apagar o historico na pagina Historico e favoritos ou pela linha de comando (python -m app.cli limpar-historico e limpar-cache).

4. Uso responsavel

Nao use este software para spam, assedio, prospeccao abusiva, discriminacao, revenda de dados (atencao aos termos do ReceitaWS) ou qualquer finalidade ilegal. O usuario e responsavel pela finalidade do tratamento (LGPD, art. 7º).

5. Limitacao de responsabilidade

Os dados podem estar desatualizados. Para fins oficiais, emita o comprovante em gov.br/receitafederal.
